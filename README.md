# Selection — 매칭 관리자 (영역별 후기 확인)

`no01_폴백_매칭수.html` : Q1 × Q3 × Q4 조합 매트릭스(그리드)로 매칭된 합격수기를 확인하고,
영역별 대표 후기/TOP 10을 선정(핀)하는 관리자 페이지.

## 구성 파일
- `no01_폴백_매칭수.html` — 매칭 관리자 페이지 (메인)
- `reviews_data.json` — 페이지가 불러오는 후기 데이터 (필수)
- `후기태그_전체.md` — 태그 매핑 단일 출처 (참고)
- `no01_폴백_매칭수.md` — 페이지 설명 문서
- `index.html` — 메인 페이지로 자동 이동(리다이렉트)

## 로컬 실행
`reviews_data.json`을 fetch 하므로 `file://` 직접 열기로는 데이터가 로드되지 않습니다.
로컬 서버로 실행하세요:

```bash
python -m http.server 8080
# http://localhost:8080/no01_폴백_매칭수.html
```
